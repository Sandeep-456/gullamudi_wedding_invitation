## Global style lock

Use the same visual language across every asset:
- South Indian temple architecture
- Bhadrachalam / Sri Rama temple inspiration
- premium Indian wedding invitation cinematography
- warm sunrise/golden-hour temple light

- rich realistic materials
- clean silhouette separation
- no text, no logos, no watermark
- no frame, no poster layout
- 16:9 for wide backgrounds; 9:16 for portrait character assets
